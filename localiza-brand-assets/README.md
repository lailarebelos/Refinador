# Localiza Brand Assets — Kit extraído do Slide Mestre oficial

Todos os arquivos são **SVGs vetoriais originais** extraídos sem alteração do arquivo
`_Template__Slide_Mestre__1__4.pptx` (Slide Mestre oficial Localiza&CO). Fidelidade: 100% — não são redesenhos.

## Estrutura

```
logos/
  localiza/          Wordmark "Localiza" (242×48) em 5 variantes de cor + símbolo "L" (48×48) em 5 variantes
  localiza-co/       Wordmark "Localiza&CO" (294×48) em 5 variantes + monograma compacto "L&CO" (48×48)
  localiza-labs/     Wordmark "Localiza Labs" (104×48) em 5 variantes
  sub-marcas/        Meoo, Seminovos, Empresas, Gestão de Frotas, eqip, Zarp
grafismos/           Recortes vetoriais das letras "L" e "&" (uso decorativo, outline 2–4px)
icones/              Sistema de ícones proprietário (balões de fala com cauda + pictogramas)
```

## Regra de uso por fundo

| Fundo | Logo a usar |
|---|---|
| Branco / claro | `*-principal.svg` (verde #018444 + folha cítrica #78DE1F) |
| Verde escuro #01602A / Verde bandeira #018444 | `*-branco-folha-citrica.svg` ou `*-branco.svg` |
| Verde cítrico #78DE1F | `*-verde-folha-branca.svg` ou `*-verde-e-branco.svg` |
| Foto / fundo preto | `*-branco.svg` (ou `*-preto.svg` em fundos muito claros) |
